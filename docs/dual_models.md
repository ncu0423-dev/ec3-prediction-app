# 21項目版と452項目版

アプリ内のサイドバーで方式を選択します。既定は「452項目版（元Notebook方式）」です。21項目版の配備モデルを保持したまま、元Notebookの452項目前処理モデルを別ファイルで配備します。切り替えても学習は実行しません。

## 入力と計算

| 項目 | 21項目版 | 452項目版（元Notebook方式） |
| --- | --- | --- |
| 入力テンプレート | 識別3列＋指定21列＝24列 | 識別3列＋全452列＝455列 |
| MolWeight | アップロード後に物質ごとに入力。任意のCSV末尾列も可 | 452項目の1つとしてCSVに入力 |
| KNN補完の距離 | 指定21項目 | MolWeightを含む全452項目 |
| 前処理 | KNNImputer(5, uniform)→StandardScaler | 同じ処理を452項目で実行 |
| 特徴量選択 | 固定21項目。Borutaによる増減なし | 全DASSの前処理後にBorutaで選択した21項目 |
| 新規予測 | 5 Foldの最小EC3 | 元Notebookの新規・外部予測と同じ最小EC3 |
| DASS検証 | 保存済みのOOF | 元Notebookと同じ、各物質を学習から除いたFoldのOOF |
| 配備ファイル | `artifacts/original_model_artifact.joblib` | `artifacts/notebook_deployment_artifact.joblib` |

全452項目の前処理を行ってから選択21項目へ絞ることと、最初から21項目だけで前処理することは異なります。元と同じ変換を必要とする場合、選択されなかった431項目についても既知の値を含む入力が必要です。

モデルを切り替えた際は、そのモデルに依存する入力編集・予測結果・分子量の追加入力・SHAPをリセットします。モデルごとの入力・結果を混在させず、性能評価も選択中のモデルに保存された数値を使用します。

## OOFとCSV一括予測の区別

元Notebookセル15では、各Foldの `Train_test_index['Test']` に対応する予測だけを `_test_pred_result` に戻します。セル224/265のDASS出力は、この検証予測を使います。その物質を学習に使った他Foldを含めて最小値を取る処理ではありません。

通常の単一・CSV予測は、新規物質の入力として全Foldで予測します。学習に使われたDASS物質を再入力した場合、他のFoldにはその物質が学習データとして含まれます。したがって、一括予測とDASSのOOFを直接比較して一致を要求することはできません。DASSとの比較には「モデルの性能評価」のOOF結果を使用してください。

配備用評価表は物質名・CAS・SMILESを除きますが、元の学習行の順序とFold・数値は保持します。

## 再現性の証拠

今回の452項目版は、`notebook_restored_model_artifact.joblib` を配備用に出力しました。この元モデルは、以前に元Notebookのモデルクラスを本番条件で独立実行し、112項目が許容差0で一致したcanonicalモデルを再利用したものです。外側5 Fold、内側5 Fold、各外側Fold1000 Optuna trials、最大100000木、early stopping15の履歴を保持しています。

今回の作業では再学習を行わず、以下を確認しました。数値の照合はすべて最大差0で一致しています。

- canonicalモデル・Notebook・DASS/newCEのSHAと、保存済み本番照合報告との一致。
- 9ライブラリ版と5 Foldすべての1000試行履歴。
- 配備コピーの452列前処理、選択マスク、学習済みXGBoost、AD/SHAP参照値の保持。
- 保存されたOOFと、各Foldの未学習行を再計算した予測の一致。
- 全DASS・外部72件の新規予測で、配備コピーと検証済み元モデルの数値一致。
- 元クラスのAD関数によるcoverage 0/.1/.2の54項目照合。

現在のAD外割合は最後のCSV出力枝に合わせて.2です。AD内Fold限定予測は対象Foldだけで集約し、対象がなければ欠損にします。最小EC3のFoldのADと、1つ以上のFoldがAD内かという判定を区別します。詳細なハッシュと検証結果は [dual_models_validation.json](dual_models_validation.json) に記録しています。

全体テストは143件成功（失敗・スキップ0）。未配布の元モデル・原本Notebookを含めず、Git管理対象のファイルだけをコピーした環境でも、両方式の予測・切り替え・テンプレート・OOF出力とNotebook画面の15件が成功しました。Streamlitサーバーの起動とHTTPヘルスチェックも確認しました。

## 再現できる範囲の限界

元Notebookは複数の探索枝を含みます。452項目版が再現するのは、セル41–42の学習条件と、最終CSV枝265/270の予測・AD規則です。元Notebookの実行不能なセル、2000 seed探索や10000回の部分抽出を、アプリの通常予測として実行するものではありません。

元PC上で過去のDASS CSVを生成した学習済みモデルとライブラリ環境は未提供のため、その過去値との完全一致は未確認です。現行環境で元クラスと一致することと、過去PCの値と一致することを区別します。

`Annex-2-in-vitro-in-silico-in-vivo-defined-approaches.csv` と `newCE_data.csv` が未提供のため、hCLAT.Callを使うin vitro AD・複合ADは完全再現できません。hCLAT.score等から推測せず、未計算として表示します。kNN ADは元の関数と照合できます。

21項目版は別に学習したモデルであり、この452項目版の一致証拠は適用しません。両方のモデルで外部EC3 R²は負です。学習手順の再現と、未知物質に対する予測性能を区別して利用してください。
