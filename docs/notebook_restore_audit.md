# Notebook仕様への復旧監査

この記録は、固定21項目版から元Notebook方式へ戻す際の独立した再確認です。
原本は `reference_private/★XGBoost_model_refact_tokunaga.ipynb`（全286セル）、
既存の詳細監査は `notebook_audit.md` を参照してください。以下のセル番号は0始まりです。

## 「同じ仕様」の比較対象

Notebookは研究途中の複数の設定・集約法・図を含み、単一の出力仕様ではありません。
最終意図の学習モデルはセル41–42（seed1037、外側5-fold、Boruta perc100、Optuna有効）、
最終報告表はセル235→265/270（kNN coverage=.20、最小EC3集約）です。
coverage=.0と.1、Fold平均との比較は別の枝として残します。

末尾セル282は探索用のOptuna無効モデルで、必須引数も不足しています。
これで最終モデルを上書きしたり、実行不能な発表図の式を予測の主仕様にしたりしません。
全セルをそのままRun Allできることと、有効な学習・推論処理を再現することを区別します。

## 数値仕様と復旧時の注意

| 項目 | 元Notebookの実装 | 固定版から戻すときの確認 |
| --- | --- | --- |

| 変換順 | KNNImputer(5, uniform) → StandardScaler → Boruta mask | 標準化前の全452列の情報をKNN距離へ使う |
| グローバル選択 | 全DASSで前処理・Boruta、support_のみ | 21項目を手指定したマスクへ置き換えない |
| Foldの前処理 | 各Foldの学習行だけで452列をfit | 保存した同じfit済みPipelineでholdout/外部をtransform |
| 目的変数 | log10(MW/EC3)、逆変換MW/(10**y) | 予測float32を指数演算前にfloat64へ変えない |
| 層別ラベル | EC3逆変換後の厳密==150、<=2、それ以外 | 生EC3、丸め、iscloseへ変更しない |
| 最終木数 | 最良trialの内側best_iterationの最大値 | 0始まりへの+1を追加しない |
| 最終集約 | 行ごとmax(y)、min(EC3) | EC3採用Foldとy採用Foldを対応させる |
| AD限定集約 | AD内Foldだけで同じ集約 | 全FoldがAD外なら欠損。通常の予測へ代替しない |
| AD全体 | 少なくとも1 FoldがAD内か | 採用FoldのADと別指標として表示 |
| 予測倍率 | predEC3 / trueEC3 | AD限定倍率knn_inAD_Fold_mispredictionもセル270の出力 |
| 複数Fold平均 | yの平均とEC3の平均は別計算 | 互いの逆変換として扱わない。最小集約と区別 |

MolWeightは元Notebookでは452列のうちの1列であり、補完距離・標準化にも入ります。
Borutaで選択されなければXGBoostの直接入力・SHAP名には含みませんが、逆変換には必要です。
固定21項目版の「換算専用で前処理にも使わない」という設定は適用しません。

手入力で全452列を用意し、非選択431列の値を空欄にすることは入力欠損の一例です。
元の完全な外部CSVと同じ情報量ではなく、同じ補完結果を保証できません。
入力列を欠いたCSVの自動補充はせず、既知の値を保持した全列CSVを推奨します。

## ADの分岐

元の式は選択・標準化後の学習点間距離から自己距離を除き、5近傍平均をソートした
`sorted_means[round(n_train*(1-coverage))-1]` を閾値とします。
queryは学習点に対する5近傍平均で `<= threshold`。補間百分位には置き換えません。

## 原本の評価指標

セル66–72には、R²/RMSEのほか以下があります。復旧時にUIへ載せるなら同じ式を使います。

- 5倍範囲は厳密な `true/5 < pred < true*5`。過大な感作性側は `pred < true/5`、
  過小な感作性側は `pred > true*5`。境界の等号を追加しません。
- GHSはEC3<=2が1A、2<EC3<=100が1B、>100がNC。
- ECETOCは<.1、[.1,1)、[1,10)、[10,100)、>=100の5区分。
- 混同行列は行=予測、列=実測。Accuracy、under/over割合も計算します。
- GHSの上記区分は学習の層別ラベル（==150等）とは違います。
  `make_llna_labels`をそのまま最終GHS分類へ使いません。
- 旧`predict.py`の閾値は一部これと異なるため、旧関数を再利用しません。

MAE・Beeswarm・通常の平均絶対SHAP重要度はWeb版の追加機能として区別できますが、
原本の式やR²/RMSEを置き換えたものとして表示しません。

## 現時点で「すべて同じ」と断定できない箇所

1. **hCLATの実験call資料が未提供。** `/workspace`全体をファイル名で検索しましたが、
   `Annex-2-in-vitro-in-silico-in-vivo-defined-approaches.csv` と `newCE_data.csv` はありません。
   セル90はDASS No.と前者のSortを対応させhCLAT.Call、セル94はnewCEのCAS Numberと
   後者のCAS no.を対応させPos/ Negを取得します。hCLAT.scoreから推定しません。
   これらがないとin vitro AD、kNNとの複合AD、およびその層別・反復評価は再現できません。
2. **保存されていない過去PCの最終モデル。** Notebookはセル35のNameErrorまでしか実行出力がなく、
   最終学習41以降の数値は保存されていません。現行の固定環境で元classを独立実行した一致と、
   当時の未保存出力との一致は別です。
3. **複数の矛盾する研究用セル。** 発表図212/214/215はlogEC3最大化で後半CSVの最小EC3と異なり、
   セル48にはFold1のIDを他Foldの値へ結合する誤り、セル124には変数名の誤りがあります。
   rawセルで関数を定義して通常セルから呼ぶ箇所など、Run All自体も成立しません。
4. **探索・反復評価と通常の推論は別。** 2000分割seed探索、10000回の外部38物質抽出、
   最高R²の集合だけを選ぶ事後解析を、標準の全72件外部評価と同一視しません。
   特に反復複合AD解析は上記hCLAT資料に依存します。

原本のクラスを分割したモジュール構成、UIの入力検査、識別情報を除いた配備コピーなどは
有効な入力での数値仕様を変える理由にはなりません。RF並列数は元の-1から資源に合わせ2へ制限していましたが、
このデータ・環境のBorutaマスクと全本番比較結果は一致しています。
「主要計算を原本仕様に復旧」と、未提供データ・矛盾セルも含めた「全セルの完全再現」を区別して報告します。
